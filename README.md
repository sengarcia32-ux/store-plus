# Note+ updates

This repository is published automatically by the Note+ build. It holds the latest
`NotePlus-<version>.ipa` and `source.json`, the update feed for SideStore.

Add this source in SideStore (Sources › +):

```
https://raw.githubusercontent.com/sengarcia32-ux/noteplus-updates/main/source.json
```

Each build replaces the contents, so only the newest version is kept.
