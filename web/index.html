How to install

  1. Set up SideStore once. It needs a computer for the first install (SideStore guide).
  2. Install LocalDevVPN from the App Store and tap Connect. SideStore needs it on while installing or updating.
  3. Tap “Add to SideStore” above. Or copy the store link and add it in SideStore › Sources › +.
  4. Open Store Plus in SideStore and tap an app's FREE button. New versions show up as Update in My Apps.

Every app is signed with your own Apple ID, not a shared certificate, so it isn't revoked. With a free Apple ID you can keep 3 sideloaded apps at once, and SideStore renews them every 7 days. Tip: in Safari, tap Share › Add to Home Screen to keep Store Plus on your Home Screen.
